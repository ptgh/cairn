# Cairn — support & privacy

The public support and privacy pages for **Cairn: Place Notes**, an iPhone app
that attaches a note to a place and surfaces it when you arrive.

- [Support](https://ptgh.github.io/cairn/)
- [Privacy policy](https://ptgh.github.io/cairn/privacy.html)

This repository holds those two pages and a stylesheet. It does not contain the
app's source.

**Support:** please [open an issue](https://github.com/ptgh/cairn/issues).
